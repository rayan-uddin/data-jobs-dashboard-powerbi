# Job Posting Dashboard | Power BI

## 📊 Project Overview

This project is an interactive Job Posting Dashboard created using Microsoft Power BI.

The goal of this project is to analyze job posting data and identify trends and insights related to job roles, locations, salaries, skills, and employment opportunities.

This project was completed as part of my learning journey in Data Analytics, following the learning material provided by Luke Barousse.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Analyze job posting trends
- Identify the most in-demand job roles
- Analyze salary information
- Understand job distribution by location
- Identify the most requested skills
- Create an interactive dashboard for exploring job market data
- Communicate data-driven insights through visualizations

---

## 🛠️ Tools & Technologies

- **Microsoft Power BI**
- **Power Query** – Data cleaning and transformation
- **DAX** – Data analysis and calculated measures
- **Excel** – Data source
- **Data Visualization** – Interactive charts and dashboards

---

## 🔄 Project Workflow

### 1. Data Collection
Job posting data was used as the primary dataset for this analysis.

### 2. Data Cleaning
The data was cleaned and transformed using Power Query.

The cleaning process included:

- Handling missing values
- Removing duplicates
- Transforming columns
- Formatting data types
- Preparing the data for analysis

### 3. Data Modeling

The cleaned data was structured in Power BI to support efficient analysis and visualization.

### 4. Data Analysis

DAX measures and calculated columns were created to analyze important job market metrics.

### 5. Dashboard Development

An interactive Power BI dashboard was created to allow users to explore job posting trends and insights.

## 🔍 Key Insights

Some of the key insights identified from the analysis include:

## 🔍 Key Insights

- The dataset contains approximately **479K job postings**, providing a broad view of the data job market in 2024.

- **Data Engineer** roles have the highest number of job postings at approximately **129K**, followed by **Data Analyst (113K)** and **Data Scientist (98K)**.

- The median yearly salary across the analyzed data jobs is approximately **$113K**, while the median hourly salary is **$48/hour**.

- **Machine Learning Engineer** roles have the highest median hourly salary at approximately **$61/hour**, followed by **Software Engineer at $60/hour**.

- **Senior Data Scientist** roles have the highest median yearly salary at approximately **$156K**, followed by **Machine Learning Engineer at $155K** and **Senior Data Engineer at $147K**.

- Job postings showed a declining trend during the second half of 2024, reaching approximately **14K in November**, before increasing to around **31K in December**.

- The analysis shows a positive relationship between **yearly and hourly salaries**, with higher-paying roles generally having higher hourly compensation.
